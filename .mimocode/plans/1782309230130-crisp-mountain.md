# Plano: Serviço Baileys WhatsApp

## Contexto

O sistema TarAJ já possui integração com WhatsApp via HTTP (chama um serviço externo Baileys). O usuário quer que o código do serviço Baileys seja criado como um projeto separado dentro do repositório.

## Estrutura

```
whatsapp-baileys/
├── package.json
├── tsconfig.json
├── Dockerfile
├── .gitignore
├── src/
│   ├── index.ts          # Express server + Baileys connection
│   └── types.ts          # Tipos compartilhados
├── auth_info/            # (gitignore) Sessão WhatsApp persistida
└── README.md
```

## Arquivos a Criar

1. `whatsapp-baileys/package.json` — deps: @whiskeysockets/baileys, express, pino, qrcode-terminal
2. `whatsapp-baileys/tsconfig.json` — target ES2020, module commonjs
3. `whatsapp-baileys/src/index.ts` — servidor Express com endpoints /status, /send, /health
4. `whatsapp-baileys/src/types.ts` — interface SendRequest
5. `whatsapp-baileys/Dockerfile` — build para produção
6. `whatsapp-baileys/.gitignore` — auth_info/, node_modules/, dist/
7. `whatsapp-baileys/README.md` — instruções de setup e uso

## Endpoints

| Método | Rota | Descrição |
|--------|------|-----------|
| GET | /status | Retorna `{ connected: boolean }` |
| GET | /health | Health check |
| POST | /send | `{ phone, message }` → envia mensagem WhatsApp |

## Verificação

1. `cd whatsapp-baileys && npm install`
2. `npm run dev` — escanear QR code
3. `curl http://localhost:3001/status` — deve retornar `{ connected: true }`
4. `curl -X POST http://localhost:3001/send -H "Content-Type: application/json" -d '{"phone":"5511999999999","message":"Teste"}'`

# Plano: Alerta de Inatividade de Tarefas

## Contexto

Adicionar um sistema de alerta que notifica o responsável quando uma tarefa fica sem movimentação por X dias. O Coordenador e o Administrador configuram o prazo (global) e os destinatários (usando o padrão existente de alert-config). Um cron job periódico verifica tarefas inativas e dispara alertas internos + e-mail.

## Desafio Central

O campo `updatedAt` das tarefas **não é atualizado** quando comentários ou anexos são adicionados — apenas quando o metadado da tarefa muda (título, estágio, etc). Precisamos de um campo `lastActivityAt` que seja atualizado em toda atividade relevante.

## Arquitetura

```
Cron (diário) → InactivityService → Query tasks(lastActivityAt < cutoff)
                                          ↓
                                  AlertConfigService → getRecipientsForEvent()
                                          ↓
                                  NotificationService → createAlert() + sendEmail()
```
